成片采用 9 段实际 Chromium 录屏与 3 段标明来源的证据/实现说明页。每段 25 秒，包含真实 HTTP 与隔离 SQLite 双身份交易；没有用静态脚本文件代替视频。旁白由本机婷婷中文语音合成，字幕与章节标题烧录在应用画面外，另附 36 条 SRT 字幕。画面由 Remotion React 组件合成，标题 y=18–106、网页 y=124–988、字幕 y=1003–1058。三个固定区域互不相交；章节动效仅出现在网页外。网页包含真实逐字输入、搜索、筛选、详情查看和交易响应；轻量指针跟随浏览器真实鼠标事件。无静帧补时、循环或截图缩放代替操作。

原创 115.2 BPM 电子配乐随章节分段编排，含鼓点、低音、短音旋律与转场音效。旁白出现时自动压低音乐，停顿时恢复。原始旁白、字幕时间轴和证据来源标注保留。

## 成片验证

- FFprobe：`300.053` 秒（9000 视频帧，AAC 封装尾差约 53 ms），H.264、1920×1080、30 fps；AAC、48 kHz、立体声音轨。
- FFmpeg 完整解码至 null 无报错；中文讲解与原创配乐混音，实测综合响度 -15.90 LUFS、真峰值 -1.44 dBTP、响度范围 7.00 LU。
- 每章抽帧检查实际内容、来源标签、中文标题/字幕、关键状态和画面边界；手机片段将窄视口居中，不拉伸原网页。
- 第 10 章明确标记既有第五次请求，FLEXIBLE/null；未宣称该次产生数值价格或再次请求模型。
- 原始现场录制过程中断言真实 HTTP 模式、无 Mock 标识、无页面错误、成交只增加一次；用户原数据库不参与录制写入。

复现依赖与命令见[交付索引](README.md)。录屏中间文件不含服务凭据；最终文件、字幕、截图和生成脚本随 PR 提交。本次为已完成交付后的视听增强，原验收证据不变；新 PR 由主任务审阅合并。

音频由本轮重新合成的中文旁白与原创配乐混合，使用旁白驱动的侧链压缩。响度由最终 MP4 解码后测量，未进行人工听审。

可编辑源码、锁文件与素材见 [video 工程](../../video/README.md)。布局及素材覆盖验证见 [verification.json](../../video/verification.json)，真实操作与 HTTP 响应时间见 [capture-events.json](../../video/capture-events.json)。这些日志不包含 Cookie、请求头、会话凭据或数据库。

交易操作后回到“我的”检查该身份的物品或预约，再回看结果；这些页面切换也是真实 HTTP 读取。运动核验只统计网页原始素材，不把标题动画或进度条算作网页操作。

帧差核验：网页原素材以 2 fps、160×90 灰度采样，逐帧平均绝对差 >0.15 记为明显变化；各章有 11–24 个变化间隔。最长近静止区间为 2.5–7.5 秒，属于输入前后、状态和统计阅读停留；没有合成静帧延长。
